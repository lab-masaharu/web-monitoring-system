# 設計判断の記録（Decision Records）

設計や運用で判断したことを、1 件 1 ファイルで残します。
後から「なぜこうなっているのか」を、AI と人間の両方が根拠付きで確認できるようにするためです。

## ルール

- ファイル名: `NNNN-短い英語の説明.md`（`NNNN` は 4 桁の連番）。
- 一度記録した判断は書き換えない。判断を変えるときは新しい記録を作り、古い記録の「状態」を「置き換え済み（NNNN）」にする。
- 議論の出典（Issue、PR、会話）があればリンクを残す。

## テンプレート

```markdown
# NNNN. タイトル

- 状態: 提案 / 採用 / 置き換え済み（NNNN）
- 日付: YYYY-MM-DD
- 関連: #Issue番号、PR番号

## 背景
## 決定
## 理由
## 影響・残課題
```
