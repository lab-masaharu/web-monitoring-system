# 作業引継ぎ（Handover）

作業を終えるときに、次の作業者（人間または AI）がすぐ再開できるよう記録を残します。

## ルール

- ファイル名: `YYYY-MM-DD-短い英語の説明.md`。同じ日に複数あれば説明を変える。
- 推測と確認済みの事実を区別して書く。
- 秘密情報は書かない。

## テンプレート

```markdown
# YYYY-MM-DD 作業の要約

- 関連: #Issue番号、PR番号、ブランチ名
- 担当: Claude Code / Codex / 人間

## 実施したこと
## テスト結果
## 未完了・未解決
## 次にやること
## 判断したこと（docs/decisions へのリンク）
```
